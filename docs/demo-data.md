# Student life demo tasks

Create these examples in the signed-in TaskFlow interface. This procedure uses the normal task form and API, so each task belongs to the account currently signed in. First confirm that this is your intended demo account. The app does not provide bulk import; create each task individually from **Create Task** and select **Save task**.

The dates below are examples based on October 18, 2026. Adjust them to future dates when preparing a later demo. Completed items can use recent past dates. Descriptions are optional but help the task list read clearly.
